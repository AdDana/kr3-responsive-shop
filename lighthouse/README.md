# Отчёты доступности

Сюда сохраняются HTML-отчёты Lighthouse после запуска `npm run audit`:

- `accessibility-index.html`
- `accessibility-catalog.html`
- `accessibility-order.html`

Для запуска требуется Chrome/Chromium. Также отчёты создаёт GitHub Actions workflow `quality.yml`, который прикладывает их к своему запуску как artifact. Скачайте HTML-файлы из artifact и добавьте в репозиторий для сдачи контрольной работы.

Результаты аудита не подменяются предположительными баллами.
